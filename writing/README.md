# Handwritten Schreiben

This directory stores task metadata/reviews, not necessarily images.

Recommended naming:

`YYYY-MM-DD-topic.md`

Each review can contain:
- original task;
- transcription if useful;
- task completion;
- key corrections;
- reusable phrases;
- retry;
- evidence added to progress.

The handwritten attempt itself may remain in the chat where it was reviewed.
